功耗档位

F7 状态机跑在内核里：L2 / L1 / L0 / L3，升级立即、降级去抖 10 秒、L3 带迟滞，热约束优先于手动「强制 L2」。这里显示的是内核下发的 mode 与 signals 自检表，页面不自行判定档位。
